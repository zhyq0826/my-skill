# 评价框架

用于面后能力评价；简历自述不能直接进入已验证能力评分。

## 证据状态

| 状态 | 含义 | 处理 |
| --- | --- | --- |
| 已证明 | 针对所评能力，有具体回答、个人动作或实作表现支持 | 按岗位标准评价，不无限外推 |
| 部分证明 | 有相关回答，但深度、边界或个人贡献尚不完整 | 说明支持的部分和未验证范围 |
| 反向证据 | 回答或实作出现实质错误，表明特定能力有不足 | 说明具体错误、适用前提和岗位影响 |
| 未验证 | 未问到、记录缺失或无法可靠判断 | 不记零分，不推断能力不足 |

一个维度可能同时有正向和反向证据，应综合说明。材料矛盾尚未核实时单列待核实，不直接认定能力不足或失实。证据状态与结论置信度分开：一个可信案例可以证明局部能力，未必支撑整项职责的判断。

## 评分锚点

优先使用用户提供的岗位量表。没有量表时先用语义判断；用户需要量化或本轮既有统一评分规则时，可使用下面的五分制，并按实际职级校准具体证据要求。

| 分数 | 含义 |
| --- | --- |
| 5 | 超出目标岗位要求，有复杂实践、清晰权衡和可验证成果 |
| 4 | 稳定满足要求，能独立完成工作并处理主要异常 |
| 3 | 基本满足常规要求，复杂边界或长期维护经验仍有限 |
| 2 | 部分相关，但实际表现暴露关键实现或失败处理不足 |
| 1 | 有明确证据显示核心理解或执行能力不符合要求 |

低分必须有表现依据，不能因为未追问个人贡献或没有时间做题就打低分。只评有证据的部分，无法支持整个维度评分时保留语义评价；不要为了填满表格虚构分数。

权重由岗位重要性决定，在出题或评分前固定，不随候选人的优势调整。没有依据时不制造精确百分比；不设置通用录用分数线。

## 汇总与覆盖

确需加权时：

```text
综合分 = Σ(已评分维度得分 × 该维度权重) / Σ(已评分维度权重)
证据覆盖率 = 已评分维度权重之和 / 全部维度权重之和
```

全部维度的权重需完整定义；分母为零时不计算。覆盖率只表示评分涉及的权重，部分证明仍须说明缺口，它不等于能力水平或结论置信度。不同候选人的覆盖范围不同，不能只按总分排序。

例如只有一个占 20% 权重的维度得到 4 分，其他维度均未验证：只能说已评分部分为 4 分、覆盖 20%，不能据此称候选人整体表现优秀或建议录用。硬门槛缺失不能被平均分和加分项掩盖。

## 结论依据的充分程度

- 依据充分：岗位关键能力有具体且相互支持的回答或实作证据，重要矛盾已核实。
- 有一定支持：部分核心职责已有证据，但仍存在会影响判断的缺口。
- 依据不足：主要来自自述、提示后复述、零散转录或未覆盖关键职责。

在结论处说明具体缺口即可，不在每段重复“样本有限”。建议下一步基于岗位要求和证据充分性，不能由模型生成一个看似客观的录用概率。
